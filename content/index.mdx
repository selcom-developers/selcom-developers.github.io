# Selcom Developers

We build open-source clients for the Selcom API gateway. They are community projects, written from scratch under the Apache License 2.0.

> **Not affiliated with Selcom Paytech Ltd.** This site and these clients are not endorsed or supported by Selcom. For API access, credentials, contracts and support, go to [Selcom's developer portal](https://developers.selcommobile.com/). Where this site and the portal disagree about the API, the portal wins.

## What you get

- Four clients that sign requests the same way and read results the same way.
- One [shared spec](/spec) that all four follow, with test vectors.
- Every layer is usable on its own: signing, transport, operations, results and webhooks.
- Safe defaults for money: no automatic retry of payments, and no default environment.

## The clients

All four are at the same stage: **v1 in development, not yet published.** You cannot install them from a package registry yet.

| Client | Language | Repository | Status |
|---|---|---|---|
| [Java](/clients/java) | Java | [selcom-developers/selcom-java](https://github.com/selcom-developers/selcom-java) | v1 in development, not yet published |
| [Node.js](/clients/node) | TypeScript and JavaScript | [selcom-developers/selcom-node](https://github.com/selcom-developers/selcom-node) | v1 in development, not yet published |
| [PHP](/clients/php) | PHP, any framework | [selcom-developers/selcom-php](https://github.com/selcom-developers/selcom-php) | v1 in development, not yet published |
| [Laravel](/clients/laravel) | PHP, Laravel | [selcom-developers/laravel-selcom](https://github.com/selcom-developers/laravel-selcom) | v1 in development, not yet published |
