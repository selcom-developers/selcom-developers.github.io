# Laravel client

> **Status: v1 in development, not yet published.** Not affiliated with Selcom Paytech Ltd.

The Laravel client is one of four community clients for the Selcom API gateway. Language: PHP (Laravel).

Repository: [selcom-developers/laravel-selcom](https://github.com/selcom-developers/laravel-selcom)

## Install

**Available after the first release.** The package is not published yet. The install line will be added here when the first release is out. Until then, follow the [repository](https://github.com/selcom-developers/laravel-selcom) for progress.

## What it follows

The client is written to the [shared spec](/spec). Read these pages to understand how it behaves:

- [Request signing](/spec/signing)
- [API v1 operations](/spec/api-v1)
- [Results and retries](/spec/results)
- [Webhooks](/spec/webhooks)
- [Client requirements](/spec/client-requirements)

In short, a client that follows the spec:

- needs an explicit environment (`sandbox` or `production`), with no default;
- signs every request, and fails closed if signing fails;
- never retries a payment or a write on its own;
- returns one of five typed statuses: `SUCCESS`, `PENDING`, `AMBIGUOUS`, `FAILED` or `NOT_FOUND`;
- verifies webhooks and treats them as hints, not proof.
