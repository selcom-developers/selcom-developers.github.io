# Laravel package

The Laravel package of the community clients. It reads its settings from your environment through a published config file and follows the same [spec](/spec) as the other clients.

Repository: [selcom-developers/laravel-selcom](https://github.com/selcom-developers/laravel-selcom)

## Install

```bash
composer require selcom-developers/laravel-selcom
```
