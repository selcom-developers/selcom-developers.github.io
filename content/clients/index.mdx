# Clients

Four community clients are in development. They follow the same [spec](/spec), so they sign requests and read results in the same way.

| Client | Repository | Status |
|---|---|---|
| [Java](/clients/java) | [selcom-developers/selcom-java](https://github.com/selcom-developers/selcom-java) | v1 in development, not yet published |
| [Node.js](/clients/node) | [selcom-developers/selcom-node](https://github.com/selcom-developers/selcom-node) | v1 in development, not yet published |
| [PHP](/clients/php) | [selcom-developers/selcom-php](https://github.com/selcom-developers/selcom-php) | v1 in development, not yet published |
| [Laravel](/clients/laravel) | [selcom-developers/laravel-selcom](https://github.com/selcom-developers/laravel-selcom) | v1 in development, not yet published |

All four are **v1 in development, not yet published**. Not affiliated with Selcom Paytech Ltd.

Not sure which to pick? See [Choosing a client](/getting-started/choosing-a-client).
