# Clients

The community clients follow the same [spec](/spec), so they sign requests and read results in the same way. Pick the one for your stack.

<LinkCards>
  <LinkCard href="/clients/java" title="Java" detail="io.github.selcom-developers:selcom4j">Java 17 or later. One runtime dependency: Jackson databind.</LinkCard>
  <LinkCard href="/clients/node" title="Node.js" detail="@selcom-developers/selcom">TypeScript and JavaScript on Node 20 or later. No runtime dependencies.</LinkCard>
  <LinkCard href="/clients/php" title="PHP" detail="selcom-developers/selcom-php">PHP 8.2 or later, any framework. PSR-18 HTTP.</LinkCard>
  <LinkCard href="/clients/laravel" title="Laravel" detail="selcom-developers/laravel-selcom">Laravel 12 or 13, built on the PHP client.</LinkCard>
</LinkCards>

Not sure which to pick? See [Choosing a client](/getting-started/choosing-a-client).
