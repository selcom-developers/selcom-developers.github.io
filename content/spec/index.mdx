# Spec

The spec is the shared source of truth for all four clients: the rules, worked examples and test vectors. This section is the spec at version `0.1.0`.

If a client and the spec disagree, the client is wrong, or the spec needs a fix that every client then picks up.

> **Not official.** The spec is not affiliated with, endorsed by or supported by Selcom Paytech Ltd. Where it and [Selcom's developer portal](https://developers.selcommobile.com/) disagree about the API itself, the portal wins.

## Test vectors

The spec ships test vectors that every client must pass:

- `vectors/signing.json`: 20 signing cases and 11 rejects.
- `vectors/responses/`: 120 response scenarios across the 16 operations, and 11 webhook samples.
- `tools/`: the Python reference implementation that generates them.

All credentials in the vectors are sample values or made up. None of them works against the gateway.

## Source

The rules, vectors and reference implementation live in one repository: [Spec repository on GitHub](https://github.com/selcom-developers/selcom-spec). Changes to the rules start there.
